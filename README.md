# WHMCS Account Reports

Developed exclusively by **[Ucartz](https://www.ucartz.com)** and released as open source under the
[MIT License](LICENSE).

A WHMCS addon module that lets logged-in clients view and export (CSV/PDF) a report of their
invoices joined against the services those invoices billed for — filterable by date range,
service, and invoice status — with a global default and a per-customer override controlling
whether the feature is available at all.

## Installation

Copy `modules/addons/accountreports/` (the whole folder, including `vendor/`) into your WHMCS
install's `modules/addons/` directory, then activate it from **Setup > Addon Modules**.

**Full documentation — use case, features, configuration, installation details, theme overrides,
security model, and maintainer notes — is in
[modules/addons/accountreports/README.md](modules/addons/accountreports/README.md).**
